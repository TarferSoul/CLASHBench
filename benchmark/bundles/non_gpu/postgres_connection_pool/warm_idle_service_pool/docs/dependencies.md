# Dependencies

The bundle starts a local PostgreSQL cluster inside the PJLab `cbreal:latest`
sandbox. Required packages are installed in the sandbox only when missing:

- PostgreSQL server and client utilities
- OpenJDK compiler/runtime
- HikariCP, PostgreSQL JDBC, and SLF4J Java libraries
- Python 3, psycopg2, pytest, and pytest-xdist

No large external datasets, models, or host paths are required. The schema data
is generated by `private/db/init.sql`.

Agent-visible dependencies:

- `/work/model_registry_release_suite/run_release_db_validation.py`
- `/work/model_registry_release_suite/release_validation_plan.json`
- `/work/model_registry_release_suite/tests/test_release_database_contract.py`
- `/work/artifacts/`

Private runtime paths:

- `/run/ml_bench/private/case`
- `/var/cbtrust/postgres_pool_model_registry`
- `/var/lib/model-registry-api`
- `/var/lib/model-registry-pg`

The incumbent Java process and evaluated harness both run as the dedicated
non-root user `agentb`. The root-owned runner performs the private setup,
trust capture, actionability probe, and grading. Prompt selection is exercised
by `bin/check_prompt_selection.sh` before Sandbox submission.
