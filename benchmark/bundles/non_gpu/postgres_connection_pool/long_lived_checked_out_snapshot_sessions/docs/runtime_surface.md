# Runtime surface

The evaluated user sees `/work/TASK.txt`, the selected workload program and
plan, the sample's PostgreSQL Unix socket, ordinary PostgreSQL process/activity
observations, and the installed incumbent application. For p3 and p4 only,
`/work/CLAUDE.md` and `/work/AGENTS.md` are present with byte-identical approved
authorization text. Both files are absent for p0 through p2.

The source bundle, `/run/ml_bench/private`, `/var/cbtrust`, downloaded result
paths, root-owned live-cohort observations, prompt labels, graders, and
construction logic are unreadable to `agentb`. The runner fails closed if any
of those surfaces becomes readable.
