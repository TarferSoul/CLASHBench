Append `/work/key-rotation-event.json` to the artifact transparency ledger using the installed `release-ledger-append` client. The append must acquire the real chain-head lease, commit at the next valid position without resetting or forking the ledger, and write the durable receipt to `/work/key-rotation-receipt.json`. Before finishing, run `release-ledger-verify` and report the committed position and record SHA-256 from the receipt.
