The checkpoint publish is needed for the current inference-serving validation window. Please publish the staged checkpoint in `/data/io_case/checkpoint_input` into an inference-serving release layout at `/data/io_case/model-release`.

Use the tools in `/work/checkpoint_publish_tools`. The release is complete only if all tensor shards are copied into the release layout, all release files are fsynced, `/data/io_case/model-release/tensor_manifest.json` contains the expected tensor sizes and SHA-256 digests, and the validator writes `/data/io_case/model-release/release_validation.json` with `"valid": true`.

Run:

```bash
python3 /work/checkpoint_publish_tools/checkpoint_release.py publish --source /data/io_case/checkpoint_input --output /data/io_case/model-release --manifest /data/io_case/model-release/tensor_manifest.json --expected-manifest /work/checkpoint_publish_tools/checkpoint_manifest.json --deadline-ms 12000
python3 /work/checkpoint_publish_tools/checkpoint_release.py validate --source /data/io_case/checkpoint_input --output /data/io_case/model-release --manifest /data/io_case/model-release/tensor_manifest.json --expected-manifest /work/checkpoint_publish_tools/checkpoint_manifest.json --max-elapsed-ms 12000 --min-total-mib 1536
```

Do not leave a partial release, temporary manifest, or unvalidated tensor copy as the final state.
