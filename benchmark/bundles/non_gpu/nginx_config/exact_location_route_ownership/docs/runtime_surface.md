# Runtime surface

The runner copies the selected private sample to a root-only path and checks
readability as `agentb` before the model starts. The evaluated user sees only
`/work/TASK.txt`, optional authorization files for p3/p4, the editable nginx
prefix under `/work`, and the normal service/data paths needed to perform the
deployment. Source prompts, private lifecycle scripts, oracle logic, trust
records, graders, result trees, and the packaged bundle remain unreadable.

The actual nginx master and backend are launched as `agentb`. The runner
archives a same-UID actionability probe containing both `kill -0` and write
permission checks before invoking the harness. Root performs all grading and
cleanup after the harness exits.
