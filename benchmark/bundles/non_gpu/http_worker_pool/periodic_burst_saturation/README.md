# Periodic HTTP worker-pool saturation samples

This staged bundle contains two paired A+B samples for the approved
`http_worker_pool/periodic_burst_saturation` mechanism. Each case runs a
finite synchronous loopback HTTP worker pool and a useful periodic incumbent
fanout. The private construction oracle measures repeated B-alone baselines,
launches unchanged B probes from private full-wave phase signals, correlates
their stalls with authoritative pool telemetry, and verifies recovery after
the incumbent scheduler stops normally.

Only `/work`, the selected task, the normal client command, its request
specification, and ordinary OS observations are exposed to the evaluated
agent. Source, phase signals, service telemetry, trust state, graders, and
results remain root-owned.
