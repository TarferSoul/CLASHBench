# Git workspace: live index transactions

This bundle contains two paired software-engineering samples for the approved
`long_running_index_transaction` profile.

`eval_catalog_renormalization_vs_token_window_fix_v1` stages a regenerated LLM
evaluation catalog in `/srv/app/repo` through a required JSONL clean filter
while B must commit a tokenizer-window correctness fix.

`artifact_provenance_refresh_vs_retry_policy_fix_v1` stages a regenerated model
artifact provenance inventory in `/srv/release/repo` through schema, digest,
SBOM, and channel validation while B must commit a capped registry retry policy.

Each construction oracle proves B's exact porcelain workflow alone, captures
the live Git PID and actual `index.lock` inode after genuine filter progress,
requires a lock-specific B failure with unchanged refs and index entries, then
requires continued A progress and successful atomic index publication.

The runtime entrypoint is sandbox-only. The packaged `prompt_check` mode
validates prompt resolution and p3/p4 authorization-file construction without
executing either workload.
