# Bursty CPU quota-period exhaustion samples

This staged bundle contains two paired A+B samples for the approved
`cpu_capacity/bursty_quota_period_exhaustion` mechanism. Both use useful,
recurring incumbent compute phases in the same finite Sandbox CPU cgroup as B,
with quieter phases between bursts.

The evaluated agent receives only `/work`, the selected task, and the public B
inputs. Source fixtures, phase signals, trust state, construction evidence,
graders, runner code, and result artifacts remain root-only.
