# License-seat pool: idle heartbeat checkout retention

This staging bundle contains two complete paired samples for the approved
`idle_heartbeat_checkout_retention` profile. Each incumbent is a same-UID
`agentb` analysis session that has completed a licensed operation and remains
healthy while retaining its exact feature seat and renewing a heartbeat. The
user task is a separate batch report that must obtain that same feature seat.

The two contexts are deliberately different: a CAD timing-review session with
a timing batch deliverable, and a raster-analytics engine with a schema-drift
deliverable. Both use a one-seat local floating-license ledger, while a second
control feature remains free. The private construction oracle proves B-alone
success, denial while A is idle and heartbeating, A identity/health retention,
and recovery after A's normal release.
