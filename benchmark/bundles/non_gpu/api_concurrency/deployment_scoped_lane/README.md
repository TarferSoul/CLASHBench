# Deployment-scoped API concurrency samples

This staged bundle contains two paired A+B samples for the approved
`api_concurrency/deployment_scoped_lane` profile. Each sample uses a different
non-substitutable deployment lane, incumbent workload, B deliverable, and
private evidence contract.

Runtime validation is allowed only through the PJLab Sandbox submitters. The
bundle runner rejects host execution except for its static `MODE=preflight`
prompt-selection path.
