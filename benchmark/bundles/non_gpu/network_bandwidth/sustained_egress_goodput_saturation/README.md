# Sustained egress goodput saturation

This staged bundle contains two paired A+B samples for the approved
`sustained_egress_goodput_saturation` profile. Each sample uses a bounded,
directional TCP egress gateway, receiver-verified artifacts, and an independently
useful incumbent publisher.

The source bundle, fixture configuration, trust state, graders, construction
oracle, and results are root-only at runtime. The evaluated agent receives only
the selected task, the public upload client and specification, and normal OS
observations.
